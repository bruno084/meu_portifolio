 Portfólio Pessoal 

Este é o meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades e dados de contato de forma moderna, responsiva e acessível.

 🛠️ Tecnologias Utilizadas

- HTML5: Estrutura semântica.
- CSS3: Estilização moderna, transições e efeitos de brilho (*glow*) customizados.
- JavaScript (ES6+): Lógica para alternância do tema (Dark/Light Mode).
- Google Material Symbols & Devicon: Iconografia para tecnologias e redes sociais.

 ✨ Funcionalidades

- 🌓 Modo Escuro / Modo Claro: Alternância dinâmica de tema com botão moderno.
- 🎨 Estilização Interativa: Efeitos de iluminação colorida ao passar o mouse sobre as tecnologias.
- 📱  Design Responsivo: Adaptado para diferentes tamanhos de tela.
- 🔗 Links Diretos**: Acesso rápido aos repositórios dos projetos e perfil do LinkedIn.
